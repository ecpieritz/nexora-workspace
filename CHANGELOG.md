# Changelog

## 2.0.0 — 2026-10-06

- Replaced mock-backed business workflows with an Express and PostgreSQL REST API.
- Added JWT authentication, refresh sessions, password recovery and workspace authorization.
- Added Prisma migrations, repeatable portfolio demo data and complete resource APIs.
- Connected Angular authentication, customers, products, invoices, schedules, tasks and dashboard reporting to HTTP repositories.
- Added production containers for Angular/Nginx, Express and PostgreSQL with automated migrations and health checks.
- Expanded CI with database migrations, API integration tests, fullstack builds and production image validation.
- Documented the fullstack architecture, local workflow, demo account and production deployment.

## 1.0.0 — 2026-08-05

- Added complete authentication and guarded workspace navigation.
- Added dashboard, invoices, schedules, tasks, calendar, customers and products.
- Added browser-backed mock API workflows and responsive layouts.
- Added accessible feedback states, toast notifications and confirmation dialogs.
- Added automated quality checks, tests and portfolio documentation.
